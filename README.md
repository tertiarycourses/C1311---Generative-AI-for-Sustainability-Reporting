## Lab Activities

The 8 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

### Topic 1 — Getting Started with Generative AI for Sustainability Reporting

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Set the Reporting Boundary and AI Control Contract](labs/lab-01-set-the-reporting-boundary-and-ai-control-contract.md) | A reporting-basis.md, ai-use-charter.md and prompt-log.csv that define scope, permitted data, prompt controls, review gates and a reproducible first AI-assisted task. |
| **2** | [Build the Framework and Materiality-Lens Register](labs/lab-02-build-the-framework-and-materiality-lens-register.md) | A framework-and-applicability-register.csv plus materiality-lenses.md showing purpose, audience, lens, requirement source, effective-date check, applicability owner and unresolved questions. |

### Topic 2 — AI for ESG Data Collection and Analysis

| # | Activity | Outcome |
|---:|----------|---------|
| **3** | [Create the ESG Evidence Register and Data Dictionary](labs/lab-03-create-the-esg-evidence-register-and-data-dictionary.md) | A data-dictionary.csv, esg-evidence-register.csv and structured-esg-data.csv containing raw and normalised values, source IDs, owners, periods, boundaries and review status. |
| **4** | [Calculate Scope 1, Scope 2 and Intensity Metrics](labs/lab-04-calculate-scope-1-scope-2-and-intensity-metrics.md) | An emissions-workpaper.xlsx or emissions-workpaper.csv set containing calculation rows, annual summaries, intensity metrics, control checks, a variance note and complete factor provenance. |
| **5** | [Run Materiality, Gap and Visual Analysis](labs/lab-05-run-materiality-gap-and-visual-analysis.md) | A materiality-gap-analysis.xlsx or CSV set with scoring anchors, topic evidence, two separate lens scores, framework-gap status, a labelled chart, reviewer decisions and a follow-up plan. |

### Topic 3 — AI for Drafting and Structuring Reports

| # | Activity | Outcome |
|---:|----------|---------|
| **6** | [Draft and Validate an Evidence-Grounded Disclosure](labs/lab-06-draft-and-validate-an-evidence-grounded-disclosure.md) | A style-sheet.md, disclosure-draft.md, claim-ledger.csv and executive-summary.md with source-linked claims, consistent units, balanced wording, unresolved limitations and recorded human decisions. |

### Topic 4 — AI for Compliance, Frameworks and Continuous Reporting

| # | Activity | Outcome |
|---:|----------|---------|
| **7** | [Build the Framework Crosswalk and Assurance Evidence Index](labs/lab-07-build-the-framework-crosswalk-and-assurance-evidence-index.md) | A framework-crosswalk.csv, assurance-evidence-index.csv and control-matrix.csv with requirement IDs, report locations, evidence lineage, owners, statuses, exceptions and reviewer sign-off. |
| **8** | [Design the Recurring Reporting Workflow and Final Pack](labs/lab-08-design-the-recurring-reporting-workflow-and-final-pack.md) | A reporting-calendar.csv, workflow-board.csv, data-contracts.md, final-pack-index.md and post-cycle-review.md covering the complete scope-to-publication cycle and its evidence-controlled AI tasks. |

## About

This repository contains the complete lab and courseware package for **Generative AI for Sustainability Reporting** (**C1311**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Set the Reporting Boundary and AI Control Contract** to **Design the Recurring Reporting Workflow and Final Pack**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **8 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **Approved AI assistant · Spreadsheet · Text editor** and the supporting resources supplied in the repository.
- Begin with **Set the Reporting Boundary and AI Control Contract** and finish with **Design the Recurring Reporting Workflow and Final Pack**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **Approved AI assistant · Spreadsheet · Text editor**. Follow the setup and access notes in each lab.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C1311---Generative-AI-for-Sustainability-Reporting.git
cd C1311---Generative-AI-for-Sustainability-Reporting
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–8 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
